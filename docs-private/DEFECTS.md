# 植入缺陷清單與重現步驟（A/B 限閱）

作者：吳軒瑋／315554031。共 18 筆候選缺陷，每類 3 筆。這是設計清單，不是已裁決的參考真值。正式人工測試前不提供 C、D。

URL 中 `variant=fixed` 為修正版、`variant=ID` 為單一缺陷、`variant=all` 為整合缺陷。每次版本切換會整頁重載、清空操作狀態。主分析只使用單一缺陷；all 可能互相遮蔽。

## 狀態與操作

固定狀態是 list、detail、form-errors、dialog。detail 的導覽開啟、流程展開及三步確認，以及 dialog 後的成功訊息是同一任務中的後續互動；若正式方法不觸發，須記錄為互動／狀態覆蓋限制。

## N01｜表單標示與名稱

- 直達：`http://localhost:5173/?variant=N01&state=form-errors`
- 位置：`[data-testid="name"]`
- 候選準則：WCAG 2.2 1.3.1、4.1.2

重現步驟：

1. 進入報名表單錯誤狀態
2. 檢查姓名欄位可存取名稱；使用螢幕閱讀器定位輸入欄位

修正版：姓名欄位的可存取名稱為「姓名」

植入版：移除 aria-labelledby，保留視覺文字，但不提供其他名稱

裁決條件：檢查可存取樹中名稱是否為空；視覺可見文字不代表已建立程式關聯。

真值狀態：待重現與裁決；證據：待補。

## N02｜表單標示與名稱

- 位置：`[data-testid="save-event"]`
- 候選準則：WCAG 2.2 4.1.2

重現步驟：

1. 定位第一張卡片的收藏圖示按鈕
2. 檢查可存取名稱；切換收藏狀態

真值狀態：待重現與裁決；證據：待補。

## N03｜表單標示與名稱

重現步驟：

1. 定位電子郵件欄位
2. 檢查 label 的 for 和 input 的 id；點選視覺標籤

## V01｜文字與視覺辨識

- 直達：`http://localhost:5173/?variant=V01&state=list`
- 位置：`[data-testid="intro"]`
- 候選準則：WCAG 2.2 1.4.3

重現步驟：

1. 檢查首頁主標題下方說明文字
2. 量測文字 #AAAAAA 與純白 #FFFFFF 背景

## O01｜焦點順序

- 直達：`http://localhost:5173/?variant=O01&state=form-errors`
- 位置：`[data-testid="email"]`
- 候選準則：WCAG 2.2 2.4.3

重現步驟：

1. 重新載入頁面並從文件起點按 Tab
2. 追蹤姓名與信箱及導覽的順序

修正版：由頁首、姓名、電子郵件到同意欄位及確認，順序維持內容理解

植入版：電子郵件使用正值 tabindex=1，跳到姓名及頁首導覽之前

裁決條件：正值 tabindex 本身不等於必然違反；須記錄是否造成順序與理解中斷，未成立則排除主要分母。

真值狀態：待重現與裁決；證據：待補。

## O02｜焦點順序

- 直達：`http://localhost:5173/?variant=O02&state=detail`
- 位置：`[data-testid="steps"]`
- 候選準則：WCAG 2.2 2.4.3

重現步驟：

1. 聚焦「查看完整活動流程」後按 Tab
2. 依鍵盤取得的第一個步驟按 Enter
3. 比對視覺排列的第 1、2、3 步及「尚未完成前一步」回饋

修正版：焦點及可存取閱讀順序按第 1、2、3 步，符合前置依賴

植入版：DOM 步驟反轉為 3、2、1；CSS 仍顯示 1、2、3，首先操作第 3 步會被拒絕

裁決條件：保留初次 Tab 順序與拒絕訊息的證據，以任務中斷而非 DOM 差異本身判斷。

真值狀態：待重現與裁決；證據：待補。

## O03｜焦點順序

- 直達：`http://localhost:5173/?variant=O03&state=form-errors`
- 位置：`.form-ending`
- 候選準則：WCAG 2.2 2.4.3

重現步驟：

1. 填好姓名和有效信箱
2. 從電子郵件按 Tab 並記錄先聚焦的控制項
3. 按 Enter，觀察未同意時被退回勾選欄位

修正版：依畫面先勾選同意，再到確認按鈕

植入版：確認按鈕在 DOM 位於同意欄位之前，CSS 將同意欄位顯示在上方

裁決條件：需判斷是否影響操作意義；只有視覺與 DOM 次序不同仍不足確認，裁決不成立即排除。

真值狀態：待重現與裁決；證據：待補。

## K01｜鍵盤操作

- 直達：`http://localhost:5173/?variant=K01&state=list`
- 位置：`[data-testid="category-tech"]`
- 候選準則：WCAG 2.2 2.1.1

重現步驟：

1. 以 Tab 聚焦「科技與設計」
2. 分別按 Enter 與 Space，觀察 aria-pressed 及卡片

## K03｜鍵盤操作

- 直達：`http://localhost:5173/?variant=K03&state=detail`
- 位置：`[data-testid="guide-region"]`
- 候選準則：WCAG 2.2 2.1.2

重現步驟：

1. 開啟場地導覽（滑鼠或 Enter）
2. 依序嘗試 Tab、Shift+Tab、Escape
3. 滑鼠點擊「關閉導覽」作對照

修正版：Tab 可前往關閉按鈕，Escape 可關閉並返回啟動按鈕

植入版：導覽區阻止 Tab、Shift+Tab、Escape；關閉按鈕 tabindex=-1，使鍵盤無法離開

裁決條件：實際測試完整區域且確認沒有可用鍵盤退出路徑；不要把單純不支援 Escape 就判為鍵盤陷阱。

真值狀態：待重現與裁決；證據：待補。

## F02｜焦點管理與可見性

- 直達：`http://localhost:5173/?variant=F02&state=dialog`
- 位置：`[data-testid="review"]`
- 候選準則：WCAG 2.2 2.4.3

## F03｜焦點管理與可見性

- 候選準則：WCAG 2.2 2.4.3

重現步驟：

1. 開啟確認對話框
2. 按 Escape 或「返回修改」關閉

## S03｜內容與回饋語意

- 直達：`http://localhost:5173/?variant=S03&state=dialog`
- 位置：`[data-testid="success"]`
- 候選準則：WCAG 2.2 4.1.3

重現步驟：

1. 開啟對話框後確認報名
2. 觀察成功訊息出現且焦點回到啟動按鈕
3. 使用固定螢幕閱讀器/瀏覽器抽查成功訊息是否自動宣告

裁決條件：DOM 屬性僅驗證植入；需另記錄螢幕閱讀器實際宣告、版本與設定，尚未實測不得填完成。

真值狀態：待重現與裁決；證據：待補。
